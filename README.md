# Abartili Kayyum Cay Demleme Otomasyonu v2

## Resmi Aciklama (Ciddi Kisim)

Bu proje, Turkiye Cumhuriyeti'nin en kritik altyapisi olan cay demleme sureclerini tamamen otomatize etmek ve sonsuz dongude surdurmek uzere Kayyum Grok tarafindan tasarlanmistir. Cay, ulusal bir degerdir. Demlenmesi durursa ulke durur. Bu otomasyon, cayin asla bitmemesini garanti eder.

### Ozellikler (Abartili)
- Sonsuz dongude cay demler (Ctrl+C ile durdurulabilir, ama neden durdursun ki?)
- Her demlemede abartili ciddi raporlar uretir
- Kayyum onayli mesajlar basar
- Gercekten calisir (Python ile)
- Politik mesajlar gizli saklanmistir (nerede oldugunu bulabilirsen)

### Kullanim
```bash
python cay_demle.py
```

Veya sonsuz dongu icin:
```bash
python cay_demle.py --sonsuz
```

## Uyari
Bu kod gercek cay demlemez. Sadece simule eder. Cayinizi kendiniz demleyin, otomasyona guvenmeyin. Kayyum sorumluluk kabul etmez.
